The guides follow the operator's path from setup through purchasing, stock, billing, money out, reports, and backup. Each chapter links the screen and its related dialogs or expanded panels. Screenshots use synthetic demonstration records. Amounts, names, and dates in them are examples.

The screenshots were rendered from the Windows UI smoke test; the table pages, Settings and the update window were refreshed on 25 October 2026 for release 1.1.0. Controls and workflows were checked against the current XAML and code behind. Physical printers, scanners, removable drives, and live accounting data require a store walkthrough.
