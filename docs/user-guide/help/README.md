# Screen help

[English guide](../english.md) · [ગુજરાતી માર્ગદર્શિકા](../gujarati.md) · [Guide index](../README.md)

Every page and dialog has an **ⓘ** beside its title (a dialog without a title shows it beside its buttons) and one help file per language in this folder. The app shows the file when the ⓘ is clicked or F1 is pressed, and the same file is that screen's page in the user guide. The file name is the topic that the screen's root names with `p:ScreenHelp.Topic`; a window built in code, or one that serves two purposes, such as Return and Void, names it with `ScreenHelp.SetTopic` (revised plan §16).

## Writing a help file

- Start with `# Title`, the screen's title as shown, then one paragraph that says what the screen is for. The ⓘ tooltip shows that paragraph.
- Use `##` sections, paragraphs, `-` or `1.` lists and two-column tables, nothing else. The app leaves out images, link targets and `<!-- comments -->`, so a screenshot can sit under the summary for the guide.
- In a table, name the screen's fields, columns or buttons in **bold** in the first column, exactly as the screen labels them; case, spaces and a trailing ▾, …, : or * do not matter. F1 in a field marks every row whose bold name is that field's label. A test fails when a bold name is not a label the app shows, and the UI smoke test fails when a column or filter on a page has no row, so a renamed or new label needs its help changed in the same commit.
- On a screen with tabs, give each tab its own section headed with the tab's name, or with the name, a colon and more, such as "Lots: filters". The ⓘ opens the help at the open tab's first section, and F1 in a field marks that field's rows in the open tab's sections first, so "Name" on the Brands tab marks the Brands row.
- The Gujarati file has the same sections, tables, rows and list items as the English one and uses the Gujarati labels from the screen. Write numbers in English digits only, and બેચ for lot (never લોટ). Mark machine-drafted Gujarati with `<!-- MT – needs review -->` until it is reviewed.
- Add new files to the table above. The app embeds every `en/*.md` and `gu/*.md` file; a file without a screen fails the tests.
