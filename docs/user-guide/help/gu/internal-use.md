# આંતરિક ઉપયોગ માટે વાપરો

દુકાનમાં વપરાયેલો આંતરિક ઉપયોગના ઉત્પાદનનો સ્ટોક નોંધો, જેમ કે થેલીઓ કે સફાઈનો સામાન.

જથ્થો બેચમાંથી ઘટે છે. આંતરિક ઉપયોગનો સ્ટોક બિલિંગ અને નફા-નુકસાનથી બહાર રહે છે.

## ખાનાં

| ખાનું | અર્થ |
|---|---|
| **જથ્થો** | કેટલું વપરાયું, બેચના સ્ટોક સુધી. |
| **કારણ** | તે શેના માટે વપરાયું. |

## બટન

| બટન | શું કરે છે |
|---|---|
| **સાચવો** | જથ્થો બેચમાંથી ઘટાડે છે. |
| **રદ કરો** | ફેરફાર વગર બંધ કરે છે. |
