# પરત ઇતિહાસ

એક ખરીદીનાં વિક્રેતા પરત જુઓ અને ભૂલથી નોંધાયેલું પરત રદ કરો.

પરત રદ કરવાથી તેના એકમો સ્ટોકમાં અને તેની ક્રેડિટ વિક્રેતાની બાકી રકમમાં પાછાં આવે છે, અને રદ કરવાના દિવસે કર પાછો ઉમેરાય છે. પરત થયેલી બેચ પછી ખાલી થઈને કાઢી નખાઈ હોય તો એકમો એ બેચની ખરીદ કિંમત, કર, બેચ નંબર, મુદત અને કિંમતો સાથે નવી બેચમાં જાય છે.

## કોષ્ટક

| કૉલમ | અર્થ |
|---|---|
| **દસ્તાવેજ** | પરતનો નંબર. |
| **તારીખ** | પરતનો દિવસ. |
| **જમા** | વિક્રેતાએ તેના માટે જમા આપ્યું તે. |
| **પડતર મૂલ્ય** | પાછા ગયેલા સ્ટોકની કિંમત. |
| **રદ કરેલ** | પરત રદ થાય પછી પસંદ થયેલું. |
| **રદ કરવાની તારીખ** | જે દિવસે રદ થયું. |

## બટન

| બટન | શું કરે છે |
|---|---|
| **પરત રદ કરો** | કારણ પૂછે છે, પછી પસંદ કરેલું પરત રદ કરે છે. |
| **પાછળ**, **આગળ** | સમાય તેના કરતાં વધુ પરત હોય ત્યારે તેમાં આગળ-પાછળ જાય છે. |
| **બંધ કરો** | વિન્ડો બંધ કરે છે. |
