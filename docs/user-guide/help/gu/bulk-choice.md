# શ્રેણી, કર દર કે ઉત્પાદનનો પ્રકાર બદલો

પસંદ કરેલાં બધાં ઉત્પાદનોને આપવાની એક શ્રેણી, કર દર કે ઉત્પાદન પ્રકાર પસંદ કરો.

શીર્ષક ક્રિયાનું નામ આપે છે, અને તેની નીચેની લીટી કયાં ઉત્પાદનો પસંદ થયાં છે તે બતાવે છે. આ વિન્ડોમાં કંઈ બદલાતું નથી: **આગળ વધો** સમીક્ષા ખોલે છે, જે બતાવે છે કે કેટલાં ઉત્પાદનો બદલાશે અને કયાં છોડાશે, અને ત્યાં લાગુ કરો ત્યાં સુધી કંઈ સચવાતું નથી.

## ખાનાં

| ખાનું | અર્થ |
|---|---|
| **શ્રેણી** | **શ્રેણી બદલો…** માટે દેખાય છે. પસંદ કરેલાં દરેક ઉત્પાદનની નવી શ્રેણી; ફક્ત સક્રિય શ્રેણીઓ યાદીમાં છે. જે ઉત્પાદન પહેલેથી તેમાં હોય તે છોડાય છે. |
| **કર દર** | **કર દર બદલો…** માટે દેખાય છે. પસંદ કરેલાં ઉત્પાદનો હવેથી જે કર દરે વેચાય અને ખરીદાય; ફક્ત સક્રિય દર યાદીમાં છે. સચવાયેલી બેચ અને બિલ તેમનો દર રાખે છે. જે ઉત્પાદન પહેલેથી આ દરે હોય તે છોડાય છે. |
| **ઉત્પાદન પ્રકાર** | **ઉત્પાદનનો પ્રકાર બદલો…** માટે દેખાય છે. **વેચાણ માટે** (બિલમાં વેચાય) અથવા **આંતરિક ઉપયોગ** (દુકાનમાં વપરાય અને બિલ તથા નફા-નુકસાનથી બહાર). સ્ટોકવાળું ઉત્પાદન તેનો પ્રકાર રાખે છે અને છોડાય છે, અને જેનો પ્રકાર પહેલેથી આ જ હોય તે પણ. |

## બટન

| બટન | શું કરે છે |
|---|---|
| **આગળ વધો** | પસંદ કરેલાં ઉત્પાદનો માટે સમૂહ ક્રિયાની સમીક્ષા ખોલે છે. કંઈ પસંદ ન કર્યું હોય તો એક વિકલ્પ પસંદ કરવાનું કહે છે. |
| **રદ કરો** | વિન્ડો બંધ કરે છે; કંઈ બદલાતું નથી. |
