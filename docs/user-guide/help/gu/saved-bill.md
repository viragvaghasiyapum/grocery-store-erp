# સાચવેલું બિલ

અધૂરું રહી ગયેલું બિલ આગળ વધારો, અથવા તેને કાઢી નાખીને નવું બિલ શરૂ કરો.

બિલિંગ એક જ અધૂરું બિલ રાખે છે. બિલ ચૂકવાય તે પહેલાં તમે બિલિંગ છોડો, અથવા એપ બંધ કરો, ત્યારે બિલ સચવાય છે, અને પછી બિલિંગ ખૂલે ત્યારે આ પૂછે છે. પ્રશ્નની નીચેની લીટી બતાવે છે કે બિલ ક્યારે શરૂ થયું, તેમાં કેટલી લાઇન છે, તેની રકમ કેટલી છે અને, હોય તો, તેનો ગ્રાહક. આ પ્રશ્નમાં બંધ કરવાનું બટન નથી: બેમાંથી એક પસંદ કરો.

## બટન

| બટન | શું કરે છે |
|---|---|
| **બિલ ચાલુ રાખો** | બિલ ખોલે છે, જેથી તેને આગળ વધારી શકાય. Enter પણ એ જ કરે છે. |
| **બિલ કાઢી નાખો** | બિલ અને તેની લાઇન કાઢી નાખે છે. બિલે સ્ટોક, નંબર કે ચુકવણી લીધાં નથી, એટલે બીજું કશું બદલાતું નથી. |
