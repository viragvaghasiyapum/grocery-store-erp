# Performance evidence

Create one `<version>.md` file for each release. Record the test PC, database generator seed and
scale, app commit, each target's median/p95, the previous result and percentage change. A result
over the target or more than 20% slower than the previous release blocks release.

The canonical full data set is generated by `GroceryErp.DataGen` with its default scale. For quick
developer checks, pass `--scale=0.001`; scaled runs are smoke tests and are not release evidence.
